# Specification

The specification for azoth lives at **[docs/src/architecture/specification.md](docs/src/architecture/specification.md)**.

It is kept in one place on purpose. A second copy here would be a second answer to what
azoth is, and the two would drift — which is the failure this repository is organised
against everywhere else, and would be a poor place to make an exception. The file lives
under `docs/src/` so that it is rendered into the documentation book with the rest of
the project, where a reader arriving at azoth for the first time will find it; this page
exists so that someone reading the repository on GitHub is not left looking for it.

Read it if you are deciding whether a change belongs in azoth, why it is written in Rust
rather than Java, or what it costs to add a calculation.
